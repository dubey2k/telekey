# Third-party software inside Telekey.app

- **adb** (Android Debug Bridge) from Android SDK Platform-Tools, Apache License 2.0.
  Source: https://android.googlesource.com/platform/packages/modules/adb. Notices: adb-NOTICE.txt.
- **scrcpy-server** from scrcpy by Genymobile and Romain Vimont, Apache License 2.0.
  Source: https://github.com/Genymobile/scrcpy. Telekey runs it on the TV for the session; it deletes itself afterwards.
